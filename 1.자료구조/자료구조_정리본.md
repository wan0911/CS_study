> **Array vs Linked List**
> 
- **Q. Array(배열)?**
    
    > 배열은 `메모리 상에 데이터를 연속적으로 저장`하는 자료구조입니다. 
    `인덱스`를 통해 특정 위치에 바로 접근할 수 있어 데이터 접근에  O(1)으로 속도가 빠르고 용이합니다. 
    반면, 데이터 크기가 고정되어 있고 데이터가 연속적으로 존재하기 때문에 중간에 데이터 삽입/삭제가 어렵다는 단점이 있습니다.
    
<br>
    
- **Q. Dynamic Array?**

    > Dynamic Array는 배열을 필요 시 2배 크기로 확장할 수 있는 자료구조입니다. 
    > 기존 Array는 `고정 크기`라 확장이 불가능한 반면, Dynamic Array는 공간이 부족하면 기존 크기의 2배로 새 메모리를 할당하고 기존 데이터를 복제하는 `가변 크기` 구조입니다. 
    > 데이터 조회는 O(1), 중간 삽입/삭제는 O(n)으로 기본 Array와 동일한 방식을 사용합니다.
    
<br>
    
- **Q. Linked List?**
    
    > 링크드리스트는 배열과 달리 메모리 상에 `비연속적`으로 데이터가 위치하는 자료구조입니다. 
    각 노드가 다음 노드의 주소를 가리키는 방식으로 연결되어 있습니다. 
    데이터 조회엔 순차 탐색이 필요하여 O(n)의 시간이 소요되고, 삽입/삭제에는 O(1)로 속도가 빠르다는 장점이 있습니다
    
<br>
    
- **Q. Array vs Linked List 비교**
    
    > 배열과 링크드리스트는 `메모리에 데이터가 저장되는 방식`에 차이가 있습니다.
    배열은 데이터가 연속적으로 저장돼 인덱스로 바로 접근할 수 있어 조회가 O(1)로 빠르지만, 크기가 고정돼 있고 중간 삽입·삭제 시 요소를 이동시켜야 해 O(n)이 걸립니다. 
    링크드리스트는 데이터가 비연속적으로 저장돼 노드 간 연결로 접근하므로 조회는 순차 탐색이 필요해 O(n)이지만, 삽입·삭제는 O(1)입니다.
