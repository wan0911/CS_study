ASP.NET Core란?
다양한 플랫폼에서 다양한 종류의 응용 프로그램을 개발할 수 있도록 도와주는 프레임워크입니다.
C#, Visual basic 등 언어를 사용해서 웹, 모바일 어플리케이션, 응용 프로그램 등을 개발할 수 있도록 지원해주는 크로스 플랫폼.


성능 — .NET Core 이후로 크로스플랫폼(Windows/Linux/Mac 어디서든 실행 가능) + 고성능 웹 프레임워크로 재설계되어, 대규모 트래픽 처리에도 유리합니다.
MS 기술 스택과의 통합 — SQL Server, Azure, Active Directory 등 Microsoft 생태계와 자연스럽게 연동되고, C#이라는 강타입 언어를 기반으로 하기 때문에 엔터프라이즈 시스템에서 안정적이고 유지보수하기 좋습니다.


* 플랫폼 : 소프트웨어가 실행되는 환경
* 프레임워크 : 소프트웨어 개발을 위한 구조와 도구를 제공하여 개발자가 응용 프로그램을 빠르고 효율적으로 개발하게 도와주는 도구
