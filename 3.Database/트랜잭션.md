트랜잭션: 데이베이스 상태를 변화시키기 위해 실행하는 작업의 단위

트랜잭션 4대 속성(원일독지)
- 원자성: 트랜잭션의 모든 작업이 수행되거나, 수행되지 않아야 한다.
- 일관성: 트랜잭션 수행 결과는 항상 일관성 있어야 하낟.
- 독립성: 2개 이상의 트랜잭션이 동시에 실행될 때 서로 개입하면 안됨
- 지속성: 트랜잭션이 성공하면, 결과는 DB에 영구적으로 반영되어어 함.


COMMIT
: 트랜잭션이 성공적으로 끝났고, DB에 영구적으로 반영했음을 알려주는 상태

ROLLBACK
: 트랜잭션 처리 중 오류가 발생하여, COMMIT되지 않은 모든 변경 사항을 취소(트랜잭션 시작 전 단계로 돌아감)
